# 0.55.0 - 2026-07-29

## New features
- "Quoi de neuf ?": after the site is updated, a popup sums up what changed since your last visit, in plain language. Each line links to the exact change on GitHub for anyone curious. [3b1eadd]
  fr: « Quoi de neuf ? » : après une mise à jour du site, une fenêtre résume ce qui a changé depuis votre dernière visite, en langage clair. Chaque ligne renvoie au changement exact sur GitHub pour les curieux.
- The full release history is reachable any time: from the "Nouveautés" link on the About page and in the home footer, or with the "Tout afficher" button inside the popup. [3b1eadd]
  fr: L'historique complet des versions est consultable à tout moment : via le lien « Nouveautés » de la page À propos et du pied de page d'accueil, ou avec le bouton « Tout afficher » de la fenêtre.

## Documentation
- Release notes are now written for every version, going back to the guided tour (0.37.0). [3b1eadd, 543ceae]
  fr: Des notes de version sont désormais rédigées pour chaque version, en remontant jusqu'à la visite guidée (0.37.0).
