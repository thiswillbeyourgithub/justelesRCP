# 0.61.0 - 2026-10-15

## Bug fixes

- The text of many RCPs no longer shows up in the link colour as if it were clickable. [8377db3]
  fr: Le texte de nombreux RCP ne s'affiche plus dans la couleur des liens, comme s'il était cliquable.
- Images in an RCP now show up, for example the black triangle that flags a drug under additional monitoring (DEPAMIDE and others). They used to appear as a broken icon with a file name. [24121a7, df25227]
  fr: Les images d'un RCP s'affichent désormais, par exemple le triangle noir signalant un médicament sous surveillance supplémentaire (DEPAMIDE et d'autres). Elles apparaissaient auparavant comme une icône cassée suivie d'un nom de fichier.
- A few RCPs whose section titles were not marked as such now get a full table of contents. [fb23bf4]
  fr: Quelques RCP dont les titres de rubrique n'étaient pas balisés comme tels ont maintenant un sommaire complet.
- A few RCPs no longer show ordinary paragraphs in oversized heading text. [c0e2f76]
  fr: Quelques RCP n'affichent plus de simples paragraphes en très gros caractères de titre.
