# 0.69.3 - 2026-11-05

## Bug fixes

- Some European-authorization pages (e.g. MVASI) had a table of contents listing only the annex names: their summary of product characteristics is now detected even when its title is written without accents, so the table of contents lists every section again. Pages whose PDF frames each page in a box (e.g. VITRAKVI) no longer lose their sections either. [440bcbb] [abd1ae6]
