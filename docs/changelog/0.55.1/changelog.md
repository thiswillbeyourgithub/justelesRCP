# 0.55.1 - 2026-07-29

## Bug fixes
- The "Quoi de neuf ?" popup no longer stays hidden for readers who arrive straight on a drug page from a search engine: it now checks whether a guided tour is actually running, instead of guessing from a marker only the home page sets.
  fr: La fenêtre « Quoi de neuf ? » ne reste plus invisible pour les lecteurs qui arrivent directement sur une page de médicament depuis un moteur de recherche : elle vérifie désormais si une visite guidée est réellement en cours, au lieu de le déduire d'un repère que seule la page d'accueil pose.

## Improvements
- The release notes the site downloads are a third smaller: only the French text is sent, the English original stays in the code repository.
  fr: Les notes de version téléchargées par le site sont un tiers plus légères : seul le texte français est envoyé, l'original anglais reste dans le dépôt de code.
