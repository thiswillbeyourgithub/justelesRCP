# 0.55.2 - 2026-07-29

## Bug fixes
- Scrolling inside the "Quoi de neuf ?" window no longer moves the page behind it: the page is now held still while the window is open, and the notes stop scrolling at their end instead of dragging the page along.
  fr: Faire défiler la fenêtre « Quoi de neuf ? » ne fait plus défiler la page derrière elle : la page est désormais figée tant que la fenêtre est ouverte, et les notes s'arrêtent en fin de liste au lieu d'entraîner la page.

## Improvements
- On the home page, the "Nouveautés" link now sits next to the version number instead of on the line above.
  fr: Sur la page d'accueil, le lien « Nouveautés » est désormais placé à côté du numéro de version au lieu de la ligne au-dessus.
