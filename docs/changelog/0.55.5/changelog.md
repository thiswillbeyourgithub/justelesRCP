# 0.55.5 - 2026-08-07

## Improvements
- The footer of every page now says who made the site and under which licence: a link to the source code on GitHub, a link to the AGPL v3 licence the code is published under, and a link to Claude Code, which helped write it. The home page footer also links to the About page.
  fr: Le pied de page de chaque page indique désormais qui a fait le site et sous quelle licence : un lien vers le code source sur GitHub, un lien vers la licence AGPL v3 sous laquelle le code est publié, et un lien vers Claude Code, qui a aidé à l'écrire. Le pied de page de l'accueil renvoie aussi vers la page « À propos ».
- On the home page, the example drug is now a single link ("Voir un exemple : ..."), easier to tap than the short link that followed the word "Exemple".
  fr: Sur la page d'accueil, l'exemple de médicament est maintenant un seul lien (« Voir un exemple : … »), plus facile à toucher du doigt que le lien court qui suivait le mot « Exemple ».

## Documentation
- The About page now names the model used by the semantic search, with a link to its page, and states that it runs on our own server.
  fr: La page « À propos » indique désormais le modèle utilisé par la recherche sémantique, avec un lien vers sa page, et précise qu'il fonctionne sur notre propre serveur.
