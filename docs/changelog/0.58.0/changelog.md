# 0.58.0 - 2026-10-01

## Improvements
- The table of contents ("Sommaire") now goes one level deeper: under "5.2 Pharmacokinetic properties" you can jump straight to "Absorption", "Elimination", and so on. Short subtitle lines that the official documents print as plain text (very common in European EMA texts) are now recognized as subtitles. European pages also list their numbered subsections (4.1, 4.2...) in the table of contents, like national ones. [1d0ddd3]
  fr: Le sommaire va maintenant un niveau plus loin : sous « 5.2 Propriétés pharmacocinétiques », vous pouvez aller directement à « Absorption », « Élimination », etc. Les petites lignes de sous-titre que les documents officiels impriment comme du texte simple (très fréquentes dans les textes européens de l'EMA) sont maintenant reconnues comme des sous-titres. Les pages européennes listent aussi leurs sous-rubriques numérotées (4.1, 4.2...) dans le sommaire, comme les pages nationales.
- The semantic search inside a drug's page now knows which subtitle each passage sits under (for example "Elimination"), so questions about a specific topic find the right passage more reliably. [1d0ddd3]
  fr: La recherche sémantique dans la page d'un médicament sait maintenant sous quel sous-titre se trouve chaque passage (par exemple « Élimination »), ce qui l'aide à trouver le bon passage pour une question sur un sujet précis.
