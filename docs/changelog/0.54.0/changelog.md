# 0.54.0 - 2026-07-29

## New features
- Shareable results page: an address like /?q=sertraline lists every matching medicine, so you can link to a whole list and not just one page. Pressing Enter without picking a suggestion opens it too. [47a9986]
  fr: Page de résultats partageable : une adresse comme /?q=sertraline liste tous les médicaments correspondants, pour pouvoir partager une liste entière et pas seulement une page. Appuyer sur Entrée sans choisir de suggestion l'ouvre également.

## Bug fixes
- Following a shared search link no longer pops the guided tour over the results. [224f699]
  fr: Suivre un lien de recherche partagé n'ouvre plus la visite guidée par-dessus les résultats.
