# 0.63.0 - 2026-10-17

## New features

- Parallel imports (a drug imported from another EU country, which has no RCP of its own) can now be found in the search: the result opens the RCP of the original product it is imported from, and says so.
  fr: Les importations parallèles (un médicament importé d'un autre pays européen, qui n'a pas de RCP propre) apparaissent maintenant dans la recherche : le résultat ouvre le RCP du médicament d'origine dont elles sont l'importation, et l'indique. [2080bc9]
