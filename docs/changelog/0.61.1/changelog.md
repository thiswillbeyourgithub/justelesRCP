# 0.61.1 - 2026-10-16

## Bug fixes

- The "checked on" date of an RCP refreshed on the server is now the day it was really fetched from the ANSM site, instead of the day the file was copied.
  fr: La date « vérifiée le » d'un RCP actualisé sur le serveur est maintenant le jour où il a vraiment été récupéré sur le site de l'ANSM, et non le jour où le fichier a été copié.
