# 0.55.4 - 2026-08-04

## Improvements
- The semantic search inside an RCP is much easier to use on a phone. Opening it now slides it to the top of the screen and puts the cursor straight in the question field, so you can type right away, and the list of results uses all the space left below instead of a narrow strip. If results are already displayed when you reopen the box, the cursor is left alone: you probably came back to read them, not to ask something else.
  fr: La recherche sémantique dans un RCP est bien plus pratique sur téléphone. À l'ouverture, elle se place désormais en haut de l'écran et le curseur est placé directement dans le champ de question, pour taper aussitôt, et la liste des résultats occupe toute la place restante en dessous au lieu d'une bande étroite. Si des résultats sont déjà affichés quand vous rouvrez la recherche, le curseur n'est pas déplacé : vous revenez sans doute les lire, pas poser une autre question.
